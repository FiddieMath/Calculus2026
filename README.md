# 微积分（上）· 作业查分台

邓老师班 · 2026–2027 学年 秋季学期

网址：<https://fiddiemath.github.io/Calculus2026/>

这是本课程的作业发布与查分页面．打开网址就能看作业题目和附加资料；输入**学号 + 查询码**可以查看自己每次作业的完成情况、成绩和批注．

---

## 主页怎么用

1. **查分**：在主页顶部填「学号」和「查询码」，点「查询」，会弹出你各次作业的完成情况（截止时间、完成状态、成绩、批注）．
2. **作业安排**：每次作业的截止时间都在这里；题目发布后，「作业内容」那一列会出现「点击查看」，点进去就是该次作业的题目，参考答案也放在同一个页面里．
3. **附加资料**：课外补充阅读，会陆续添加．

> 提交作业请按班级约定交到原有渠道（群作业、教学平台等）．这个页面只负责发布题目和显示批改结果，**不收集作业**．

## 查询码

- 每位同学有一个专属查询码，由助教发放．查询码能看到你的成绩，**请不要转给别人**．
- **忘记查询码**：用你的**学校邮箱**（`学号@smail.nju.edu.cn`）给助教的查询邮箱发一封邮件，**主题里写上「查询码」**（正文可以留空），通常一分钟左右会自动回信告诉你查询码．助教的查询邮箱地址见班级群公告．
  - 必须用本人学号邮箱发送；用其它邮箱发来的邮件不会自动回复．
- **想改查询码**：私下联系助教．

## 表格里的状态怎么看

| 显示 | 含义 |
| --- | --- |
| 未布置 | 这次作业还没有布置 |
| 未交 | 已经布置，但还没有收到你的作业 |
| 已交 · 待批改 | 作业已收到，还没批改（成绩暂时显示「—」） |
| 迟交 · 待批改 | 迟交，还没批改 |
| 已批改 | 已批改，会给出「得分 / 满分」与批注 |
| 迟交 · 已批改 | 迟交并且已批改 |

## 常见问题

**页面没更新 / 打不开？** 发布后 GitHub Pages 大约要 1 分钟同步，强制刷新一下（电脑 `Ctrl+F5`，手机下拉刷新）．

**公式显示成代码？** 先强制刷新；仍然异常就换用较新版本的浏览器（Chrome、Edge、Safari）．

**成绩还是旧的？** 老师批改并发布之后才会更新，一般就在批改当天．

**查询码输进去没反应？** 页面会提示学号或查询码不正确，核对后重试；想不起来就用上面的邮件方式查询．
